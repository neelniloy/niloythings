# Portfolio Redesign Plan

## Core Issues Identified
1. Responsive design breaks on mobile/tablet
2. Overall UI doesn't feel premium/satisfying
3. Work section confuses projects vs. career experience
4. Tools section has limited utility (only 2 tools)

## Solutions

### 1. Work Section Restructure
**Current State**: Single page showing projects
**New Design**: 
- Add tabbed interface: "Projects" | "Experience"
- Projects tab: Showcase actual built products with clear CTAs
- Experience tab: Professional timeline with companies/roles

### 2. Tools Section Enhancement
**Add 6+ New Tools**:
- Base64 Encoder/Decoder
- URL Encoder/Decoder
- Hash Generator (MD5, SHA-256, SHA-512)
- Color Converter (HEX/RGB/HSL)
- Unix Timestamp Converter
- UUID Generator

### 3. Responsive Improvements
- Mobile-first breakpoints (sm, md, lg, xl, 2xl)
- Better touch targets (min 44px)
- Optimized typography scaling
- Stack layouts on mobile instead of grid

### 4. UI Aesthetic Overhaul
- Less "dark hacker" vibe, more "professional engineer"
- Increase whitespace and breathing room
- Softer color palette with better contrast
- Clear visual hierarchy
- Better card designs with subtle shadows

4. [ ] Fix responsive breakpoints globally
